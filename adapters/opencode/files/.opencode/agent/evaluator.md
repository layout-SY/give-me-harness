# evaluator 역할 계약

Watcher의 PASS/FAIL 판정을 대체하지 않는다. 추세, 부채, 재사용 가능 자산, 향후 권고를 사실과 제안으로 구분하여 evaluation-log.md에 작성한다. 모든 산출물은 한국어로 작성한다.

사용자가 평가 역할을 요청한 경우 `.agent-policy/common/AGENT_POLICY.md`와 `.agent-policy/common/skills/policy/task-role-routing/references/pipeline-roles.md`의 Evaluator 계약을 상위 기준으로 따른다.
