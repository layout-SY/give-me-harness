## 하위 에이전트 공통 계약

부모 세션이 호출한 모든 하위 에이전트에 직접 적용한다. 상세 기술 정책은 필요한 문서만 읽는다.

- **미확정 결정은 부모에게 반환한다.** 확인되지 않은 API·데이터·업무 정책·기본값·예외 처리·재사용 방식과, 결과·범위·동작·운영 방식을 바꾸는 설계 선택(구현 구조, 작업 순서, 담당 등)을 임의로 정하지 않는다. 확인한 근거, 누락된 항목, 둘 이상의 방안과 각 방안의 장단점·영향, 권장안을 정리해 반환하고 그 결정에 의존하는 작업은 보류한다. 사용자에게 직접 묻거나 사용자 대신 결정하지 않는다. 부모가 이미 전달한 확정 사항은 다시 묻지 않는다. 일반적인 `진행`·`Proceed`를 아직 질문하지 않은 결정의 승인으로 해석하지 않는다.
- **작업 위치를 확인한다.** 부모가 전달한 worktree 절대 경로에서만 작업하고 첫 변경 전에 실제 위치·branch·HEAD를 확인한다. 경로를 전달받지 못했거나 실제 위치가 다르면 변경하지 않고 반환한다.
- **작업 worktree로 옮긴 뒤 읽는다.** 스킬과 코드를 읽기 전에 `cd <worktree 절대 경로>`를 단독 명령으로 실행한다. source 수정을 허용하는 근거는 그 worktree를 작업 위치로 둔 상태에서 읽은 것만 기록되며, 다른 위치에서 읽었거나 `cd … && cat …`처럼 이어 쓴 읽기는 인정되지 않는다. 근거 부족으로 수정이 막히면 차단 문구가 알려 주는 위치에서 관련 SKILL.md와 대상 코드를 읽는다.
- **Git 변경은 요청만 반환한다.** branch·worktree 생성, stage, commit, merge, 삭제와 브랜치 관계 변경을 실행하지 않는다. 필요한 명령·위치·대상·영향을 반환하면 부모가 사용자 승인 후 실행한다. Git 조회는 자유롭게 한다.
- **자기 작업의 산출물만 쓴다.** 부모가 전달한 작업 ID의 산출물 위치(`tasks/<작업 ID>/`)에만 기록한다. 전달받지 못했으면 부모에게 반환하고 다른 작업의 산출물은 수정하지 않는다.
- **역할 밖의 변경은 반환한다.** 계획이 다른 하위 에이전트에 배정한 종류의 변경이 필요해지면 생성·수정·삭제 모두 직접 하지 않고 대상과 이유를 반환한다.
- **범위를 넘지 않는다.** 전달받은 작업 범위 밖의 파일이나 공용 항목(shared·lib·utils·공용 UI·hook)을 생성·수정·삭제해야 하면 변경 전에 대상과 이유를 반환한다. 다른 세션·다른 worktree의 변경을 되돌리거나 덮어쓰지 않는다.
- **재조사는 변경분만 한다.** 부모가 선행 작업의 변경 파일 목록을 전달하면 그 파일만 다시 읽고 기존 조사 결과는 유지한다.
- **현황판은 조회만 한다.** 작업 현황·브랜치 관계·병합 순서는 `python3 -I .agent-policy/runtime/git_operations.py board`로 조회한다. 공용 항목의 영향 범위는 같은 명령에 `--check <경로>`를 붙여 확인한다. 현황판 갱신은 부모가 한다.
- **결과를 구분해 반환한다.** 수행한 내용, 변경 경로, 실행한 검증과 결과, 미확정 질문, Git 요청, 다음 단계를 나누어 적는다. 모든 산출물은 한국어로 작성한다.
