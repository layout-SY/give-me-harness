# 레시피 색인

- `api-authoring`: typed Axios API, DTO/parser, TanStack Query 및 MSW 계약 조립.
- `data-dto`: DTO와 폼-페이로드 설계.
- `data-fetch`: 목록/상세/폼 데이터 흐름 조립.
- `i18n`: 사용자 노출 문자열 현지화.

반복되는 다단계 흐름에만 새로운 레시피를 추가합니다. 횡단 규칙은 `policy`로, 원자 단위의 재사용 가능 자산은 `reference`로 추가합니다.
