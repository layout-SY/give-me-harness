# <라이브러리> 사용 계약

## 목적과 적용 범위

- 해결할 요구·선택 이유:
- 대상 프로젝트·적용할 UI·제외 범위:
- 문서 상태: 계획 초안 | 구현 확인 | 중앙 등록 완료

## 버전과 근거

- 정확한 패키지명·선언 범위·lockfile 설치 버전:
- 공식 문서 URL·확인한 버전:
- 조사한 실제 코드·어댑터·사용처와 확인 시점:

## 구현 방식과 계약

- 공용 어댑터 경로·공개 import·공급자 패키지와의 의존 경계:
- 공개 props·타입·필수/선택·기본값과 공급자 API 매핑:
- controlled 상태·소유권·callback·이벤트 payload와 호출 시점:
- ref·children·접근성·키보드·포커스·스타일 계약 중 해당 항목:
- 도메인·API·상태 로직과의 연결 경계:

제안한 계약과 실제 구현된 계약을 구분한다. 적용하지 않는 항목에는 이유를 남긴다.

## 사용법

- 필요한 provider·CSS·설정과 현재 프로젝트의 구성 위치:
- 실제 공개 어댑터 import를 사용하는 최소 예시:
- 지원하는 상태·옵션과 잘못 사용하기 쉬운 점:

예시는 확인된 API로 작성하고 공급자 패키지를 기능 코드에서 직접 사용하는 예시로 대체하지 않는다.

## 제약과 검증

- 버전·환경·번들·렌더링 관련 제한과 확인 근거:
- 실제 사용처와 계약·동작 검증 방법·결과:
- 미확정 사항·갱신이 필요한 조건:

## 중앙 등록·갱신

- 세션 초안 경로·연결된 자산 선정 계획:
- 기존 정본·대상 중앙 경로·변경 이유:
- 등록·갱신 및 새 inject 세션 반영 상태:
