# 컴포넌트 참고 자료

먼저 `src/shared/ui/`를 검색합니다. 후보 경로, 계약, 접근성 동작과 재사용하거나 제외한 이유를 기록합니다. 공용 기본 요소는 `src/shared/ui/`에 두고, 기능/도메인 컴포넌트는 소유 기능 가까이에 둡니다. 이 카탈로그에는 원본 관리자 프로젝트의 컴포넌트가 존재한다는 주장을 의도적으로 포함하지 않습니다.
