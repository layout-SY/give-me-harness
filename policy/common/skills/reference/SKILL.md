# 참고 자료 인덱스

- `components/SKILL.md`: `src/shared/ui/` 아래의 자산을 조사하고 선택합니다.
- `custom-hooks/SKILL.md`: 재사용 가능한 훅을 조사하고 선택합니다.
- `libraries/SKILL.md`: 외부 UI 라이브러리의 프로젝트별 버전·어댑터 계약·사용법을 조사합니다.

참고 자료 스킬은 실제로 존재하는 자산만 설명합니다. 원본 프로젝트의 컴포넌트가 이 대상 프로젝트에도 존재한다고 단정하지 않습니다. 대상 프로젝트에 해당 자산이 추가된 경우에만 단일 책임의 참고 자료를 추가합니다.
