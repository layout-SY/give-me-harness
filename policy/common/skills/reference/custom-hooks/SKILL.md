# 커스텀 훅 참고 자료

훅을 생성하기 전에 대상 프로젝트의 `src/**/hook/**`, `src/**/hooks/**`, `src/shared/**`를 실제로 검색합니다. 상태와 effect의 소유권, 입출력 계약, 취소·정리 동작, 사용처와 변경 압력을 기록합니다.

검색 결과가 없거나 계약이 다르면 다른 프로젝트의 훅이 존재한다고 가정하지 않습니다. 최소 두 사용처가 의미와 생명주기를 공유할 때만 공용 훅으로 분리하고, 기능 전용 생명주기는 해당 feature 가까이에 둡니다.
