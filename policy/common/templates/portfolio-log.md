# 이력서·포트폴리오 기록 스키마

이 스키마는 Claude 작업에서 확정된 포트폴리오 프롬프트를 공통 정본으로 승격한 것이다. 하나 이상의 완전한 사례에 작업 유형, 관련 도메인/서비스, 문제 출처, 문제 상황, 고민과 선택, 적용, 사용 기술의 구체적 목적, 결과, 사용자 후속 피드백, 이력서 bullet과 포트폴리오 서술을 포함한다.

각 `## 사례 N — 제목`은 모든 필수 하위 항목을 포함한다. 사용자 대화·현재 실행·현재 코드에 없는 선택, 성과 또는 수치를 추정하지 않는다. 정책·hook·workflow 등 AI 하네스 변경도 같은 구조를 사용한다.
