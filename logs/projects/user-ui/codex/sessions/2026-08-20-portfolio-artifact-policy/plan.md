# 계획

## 목표

변경 작업 완료 후 대화·테스트·설계 근거를 이력서·포트폴리오 사례로 추합하는 `portfolio-log.md`를 필수 산출물로 추가하고 Stop hook으로 누락과 구조를 차단한다.

## 범위

- `AGENTS.md`와 portfolio/documentation 정책 갱신.
- portfolio schema/template 추가.
- feature/refactor/hybrid workflow 갱신.
- Stop hook required artifact와 사례 구조 검사 추가.
- `.claude/**`, `CLAUDE.md`를 AI 하네스 보호 경로에 포함.
- governance 테스트와 hook 무결성 해시 갱신.

## 제외 사항

- 애플리케이션 기능 변경.
- 과거 모든 세션 문서의 소급 생성.
- 대화에 없는 성과나 사용자 선택 추정.

## 승인

- 상태: approved
- 근거: 사용자 요청 `반영해`.
