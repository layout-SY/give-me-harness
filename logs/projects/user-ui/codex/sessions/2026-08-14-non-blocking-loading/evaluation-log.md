# 평가 로그

## 현재 판정과의 경계

여기서는 Watcher 판정을 다시 평가하지 않는다.

## 장기 관찰 사항

- 전역 또는 기능별 loading 표시에는 시각 상태와 입력 차단 정책을 별도 계약으로 명시할 필요가 있다.
- 현재 `Loading`은 spinner와 overlay 역할을 함께 가진다.
- 서비스 탭은 6개 항목까지 fixed mobile shell에서 동일 폭 grid를 사용한다.

## 목록에 등록할 재사용 가능 자산

- 이번 변경은 기존 `src/shared/ui/loading` 계약 보정이며 신규 자산은 없다.

## 기술 부채

- Vitest 기본 설정은 CSS import를 빈 모듈로 변환하므로 CSSOM 회귀 테스트에 별도 파일 읽기 또는 선택적 CSS 처리 설정이 필요하다.
- 사용자 지시에 따라 이번 작업에서는 해당 테스트를 유지하지 않는다.
- 서비스 종류가 더 늘어나면 동일 폭 grid보다 수평 스크롤 또는 정보 구조 재분류가 필요할 수 있다.

## 프로세스 개선 사항

- CSS 상호작용 회귀 검증이 필요할 때 5분 이내에 테스트 하네스 적합성을 먼저 확인한다.
- 테스트 환경이 맞지 않으면 설정 확장 전에 사용자 시간 제한과 프로젝트 검증 제한을 우선한다.

## 권고 사항

향후 로딩이 사용자 입력을 의도적으로 막아야 하는 요구가 생기면 별도 blocking variant를 명시적으로 설계하고 접근성 계약을 함께 정의한다.
