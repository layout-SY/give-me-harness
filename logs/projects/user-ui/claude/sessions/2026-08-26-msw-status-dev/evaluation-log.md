# 평가 로그

## 현재 판정과의 경계

여기서는 Watcher 판정을 다시 평가하지 않는다.

## 장기 관찰 사항

- `ImportMetaEnv`가 회의 기능 폴더의 `vite-env.d.ts`에 있다. 전역 env 타입이 늘면 공유 설정 경로로 옮기는 편이 찾기 쉽다.
- `.env.template` 예외가 gitignore에 있으나 파일이 없다. 공유 환경 변수 목록이 필요하면 템플릿을 두는 편이 로컬 `.env`보다 안전하다.

## 목록에 등록할 재사용 가능 자산

없음.

## 기술 부채

- 프로덕션 빌드에 `VITE_API_BASE_URL_STATUS=dev`를 넣으면 MSW가 실서비스 요청을 가로챌 수 있다. 배포 env에서 이 값을 `dev`로 두지 않아야 한다.

## 프로세스 개선 사항

모의 스위치 이름을 API base URL status와 묶었다. 이후에는 URL 선택과 모의 사용이 같은 변수를 쓰는지 README 한 줄로 밝혀 두면 혼선이 줄어든다.

## 권고 사항

배포 환경 변수 목록에 `VITE_API_BASE_URL_STATUS`를 `dev`가 아닌 값으로 명시하면 실서버 가로채기를 막을 수 있다.
