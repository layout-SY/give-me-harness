## 사용자 결정

- Q1: A 방식. 화면 데이터에서 예상한 요청/응답 DTO와 API 연결은 logic handoff 문서에 페이지·컴포넌트별로 모두 기록한다.
- Q2: EC 고객센터·1:1 문의는 `/manage` 문의와 별개 개념. 문의 유형·사진 첨부는 피그마대로 확정하고 API 확정 시 상수값으로 추가한다고 주석·문서에 남긴다.
- Q3: 대응 화면이 없는 진입점(카테고리 탭, 알림, 더 많은 질문, 빠른 메뉴)은 버튼과 콜백만 연결한다.
- Q4: 주소 검색·배송 조회·결제 동작은 미정. 결제 수단은 "신용카드" 하나만 두고 UI 평가 요소로 남긴다.
- Q5: `embla-carousel-react` 추가.
