# 탐색

## 요청

중앙 원본 `AGENTS.md`에 프로젝트 공통 `handoff` 규칙을 정의한다.

## 대상 관련 사실

- 사용자 요청의 `~/폐기된 외부 정책 저장소` 경로는 존재하지 않는다.
- 프로젝트 `AGENTS.md`와 중앙 저장소 루트 `AGENTS.md`는 실제 중앙 원본을 `~/SynologyDrive/폐기된 외부 정책 저장소`로 지정한다.
- `source/common/AGENTS.md`에는 Claude Code production UI 작업의 `handoff.md` 예외와 기능 이식 인계 절차가 있으나, 모든 작업자·호스트·세션 전환에 적용되는 일반 인계 계약은 없다.
- 중앙 저장소 루트 `AGENTS.md`는 정책 배포 뒤 실행 중인 대상 프로젝트 세션을 handoff하고 새 세션을 시작하도록 요구한다.
- Codex용 `.codex/templates/handoff.template.md`에는 목표 및 현재 상태, 완료·대기 작업, 결정·제약, 관련 경로, 명령어 및 결과, 다음 조치 항목이 있다.
- 중앙 저장소는 Git 저장소로 인식되지 않아 중앙 원본의 변경 전 Git 상태는 확인할 수 없었다.
- 현재 대상 프로젝트 작업 트리에는 본 작업 이전의 다수 변경이 존재하며, 본 작업은 새 세션 디렉터리 외 해당 변경을 수정하지 않는다.

## 불러온 스킬

- `skill-index`: 필요한 정책 스킬만 선별했다.
- `policy-harness`: 사용자 승인, 역할 분리, Watcher/Evaluator 게이트를 적용했다.
- `policy-documentation`: 세션 산출물 위치, 결론 우선 기록, Todo 언어를 적용했다.
- `policy-review-checklist`: 승인 근거, 목표 범위, 검증과 문서화를 Watcher 판정 항목으로 채택했다.
- `policy-portfolio`: 검증 후 `portfolio-log.md`에 실제 대화·실행·변경 근거만 기록하도록 채택했다.

## `src/shared/ui/`의 재사용 가능 자산

| 후보 | 결정 | 근거 |
| --- | --- | --- |
| `src/shared/ui/**` | 사용하지 않음 | 이번 작업은 중앙 정책 문서 변경이며 UI·마크업·스타일을 생성하거나 수정하지 않는다. |

## 제약 조건 및 미확인 사항

- 중앙 원본은 현재 작업 공간의 기본 쓰기 허용 경로 밖에 있어 수정 시 별도 파일 시스템 승인이 필요하다.
- 실제 배포는 승인 범위에서 제외했으므로 dry-run까지만 수행한다.
- 생성된 대상별 diff가 기존 미배포 변경도 포함할 수 있으므로, 본 규칙에 해당하는 `AGENTS.md` 차이를 구분해 검토해야 한다.

## 결론

`source/common/AGENTS.md`의 Claude Code 병렬 협업 절 뒤에 일반 `작업 인계` 절을 추가하는 것이 적절하다. 인계 발동 조건, 기록 위치와 필수 항목, 단일 작성 책임, 수신자의 재검증, 근거 우선순위, 8종 완료 산출물과 Claude UI 예외의 관계를 규정하고 이후 절 번호를 조정한다.
