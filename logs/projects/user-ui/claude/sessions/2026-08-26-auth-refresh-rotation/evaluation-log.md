# 평가 로그

## 현재 판정과의 경계

여기서는 Watcher 판정을 다시 평가하지 않는다.

## 장기 관찰 사항

- 여러 탭이 동시에 같은 refresh를 보내면 서버가 계정 토큰을 전부 폐기할 수 있다. 탭 간 잠금은 이번 범위에 없다.
- 갱신 실패 후 로그인 라우트로 보내지 않는다. 액세스 토큰이 지워진 뒤 다음 API가 401을 낼 수 있다.
- 전송 후 응답이 오기 전에 로그인하면, 진행 중이던 refresh가 나중에 persist할 수 있다. abort/세대 가드는 넣지 않았다.

## 목록에 등록할 재사용 가능 자산

없음. `authSession`은 인증 기능 내부 헬퍼다.

## 기술 부채

- 탭 간 refresh 잠금이 없다.
- 실패 후 로그인 화면 이동이 없다.

## 프로세스 개선 사항

1회용 토큰 스펙은 요청/응답 JSON만으로는 부족하다. 재사용 시 폐기 규칙을 세션 계층 완료 조건에 같이 적는 편이 안전하다.

## 권고 사항

탭을 여러 개 쓰는 흐름이 생기면 storage 이벤트로 in-flight를 공유할지 별도로 받으면 된다.
