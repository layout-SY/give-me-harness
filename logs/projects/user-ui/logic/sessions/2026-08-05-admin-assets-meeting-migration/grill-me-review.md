# Grill Me 검토

## Method Guardrails (검토 방법 안전장치)

- [x] neutral question-first 적용 여부
- [x] 질문이 검토자를 구현 선택으로 유도하지 않음

## Neutral Question Flow (중립 질문 흐름)

| 영역 | 중립적 질문 | 답변 | 근거 | Recommended Answer (권장 답변) |
| --- | --- | --- | --- | --- |
| 범위 | 요청한 대상 기능에 필요한 소스 자산은 무엇인가? | 운영 지침 정의, 전체 공유 폐쇄, 회의 기능이 필요하며 소스 이력과 관리자 도메인은 불필요하다. | `exploration.md`와 대상 매니페스트 | 저장소 전체가 아닌 의존성 폐쇄를 이전한다. |
| 안전 | 그대로 유지해야 하는 대상 상태는 무엇인가? | React/Vite 컴파일러 설정, npm 소유권, 비밀값 경계, 승인된 회의 진입점으로 교체하기 전까지 무관한 시작 자산이다. | 패키지와 구성의 변경 내역 및 `.env.template` | 구성을 조정하고 잠금 데이터를 다시 생성한다. |
| 동작 | 충실한 이전을 입증하는 회의 불변 조건은 무엇인가? | 참여 시도 소유권, 리스너 정리, 트랙 해제, 퇴장 순서, 토큰 갱신, 참여자 상태이다. | `src/features/meeting/hook/`와 `lib/agoraClientEvents.ts` | 생명 주기 모듈을 기능 내부에 유지한다. |
| 접근성 | 미디어나 색상 없이도 이해할 수 있어야 하는 관찰 가능 상태는 무엇인가? | 한국어 레이블, 실시간 상태, 중립적인 참여 전 컨트롤, 명확한 포커스, 검증 알림, 모션 감소이다. | Playwright 및 시각 품질 검증 PASS | 접근 불가능한 상태 의미가 있으면 릴리스를 차단한다. |
| 근거 | 로컬 검증으로 결론 내릴 수 없는 것은 무엇인가? | 유효한 서버 자격 증명 없이 실제 Agora 참여/게시/구독이 성공하는지 여부이다. | 자격 증명을 복사하거나 임의 생성하지 않음 | 외부 검증 제한으로 기록한다. |

## 결론

선택한 이전 경계는 대상 소유권과 비밀값 경계를 유지하면서 요청을 충족하는 최소 완결 집합이다.
