# 평가 로그

## 현재 판정과의 경계

여기서는 Watcher 판정을 다시 평가하지 않는다.

## 장기 관찰 사항

- `customConfig`/`authRequired`는 헤더 부착에 더 이상 쓰이지 않는다. 다음 정리에서 API 파일의 중복 플래그를 지울 수 있다.
- 로그인 요청에도 이전 토큰이 붙는다. 서버가 이를 거부하면 로그인만 제외하는 옵트아웃이 필요할 수 있다.

## 목록에 등록할 재사용 가능 자산

`attachAccessTokenHeader`는 공유 Axios와 인증 Axios가 같이 쓰는 전송 헬퍼다.

## 기술 부채

- 시민참여 API의 `customConfig` 확산은 이제 죽은 인증 스위치다.
- 회의 `meeting.api.test.ts` insecure 케이스 2건은 구현에서 해당 검증이 주석이라 기존 실패로 남는다.

## 프로세스 개선 사항

인증이 필요한 요청을 파일마다 표시하면 GET이 빠진다. 이후에는 기본 인증, 예외만 명시하는 쪽이 누락이 적다.

## 권고 사항

토큰 부재 시 보호 API를 호출하지 않게 하려면 인터셉터에서 실패를 던질지 별도로 확정하면 된다.
