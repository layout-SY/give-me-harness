# 평가 로그

## 현재 판정과의 경계

여기서는 Watcher 판정을 다시 평가하지 않는다.

## 장기 관찰 사항

- `/me/activity` 응답이 목록과 다른 필드(요약 문구 등)를 갖게 되면 `useMyProposalActivityQuery`와 내 활동 제안 필터 매퍼를 다시 나눠야 한다.
- vote/discussion 토글은 아직 옛 activity 응답을 쓴다. 타입이 확정되면 같은 패턴으로 분리할 수 있다.

## 목록에 등록할 재사용 가능 자산

없음.

## 기술 부채

- 내 활동 화면 제안 필터는 요약 문구를 빈 문자열로 둔다. 확정 목록 응답에 해당 필드가 없다.
- 목록 카드 `summary`는 여전히 빈 값이다.

## 프로세스 개선 사항

필터 API는 요청과 응답을 함께 확정하면 목록 DTO 재사용 가정을 피할 수 있다.

## 권고 사항

activity 응답 OpenAPI가 오면 `parseProposalList` 재사용 여부를 먼저 검증한다.
