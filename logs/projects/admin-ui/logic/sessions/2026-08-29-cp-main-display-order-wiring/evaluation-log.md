# 평가 로그

## 현재 판정과의 경계

여기서는 Watcher 판정을 다시 평가하지 않는다. 현재 변경은 Watcher PASS이며 아래 내용은 장기적인 개선 가능성이다.

## 장기 관찰 사항

- 화면 배열 위치와 `order` 값이 같은 의미를 가져야 한다는 전제가 모델과 저장 계약에 걸쳐 존재한다.
- model → process → controller → view의 wiring은 타입과 빌드로 확인되지만 전용 통합 테스트는 제한적이다.

## 목록에 등록할 재사용 가능 자산

- 현재는 없음. 순서 이동 모델이 다른 도메인에서 반복될 때 재사용 후보로 재평가한다.

## 기술 부채

- 배열 위치와 `order` 정규화 규칙을 서버 계약 문서에서 명시하면 향후 구현 간 해석 차이를 줄일 수 있다.
- 사용자 이벤트에서 저장 payload까지 이어지는 wiring 자동화 테스트가 추가되면 중간 계층 누락을 더 직접적으로 탐지할 수 있다.

## 프로세스 개선 사항

- linked worktree에서도 LSP 진단이 가능하도록 요청 cwd와 worktree 경로 처리 방식을 정비할 필요가 있다.
- 전체 lint의 기존 오류와 변경 파일 lint 결과를 CI에서 분리해 신규 오류 유입 여부를 명확히 표시할 수 있다.

## 권고 사항

- 현재 릴리스 차단 사항은 없다.
- 두 번째 순서 이동 사용처가 생기거나 서버 계약이 확장될 때 정규화 규칙과 공용화 여부를 함께 검토한다.
