# Styles (Policy)

## 언제 이 스킬을 사용하나요?

- 새 아이콘/SVG/이미지를 추가할 때
- 버튼·인풋 등 공용 컴포넌트 스타일을 수정해야 할 때
- 페이지 레벨에서 독자 스타일을 만들기 전에 재사용 가능성을 판단할 때

## 규칙

- **이모지를 직접 생성하지 않는다** (코드/UI에 이모지 문자 사용 금지). SVG 등 정식 자산으로 대체
- 스타일 수정 전 해당 공용 컴포넌트(`reference/components/<x>`)의 기존 스타일을 먼저 확인
- 동일한 시각 패턴이 2회 이상 반복되면 공용 컴포넌트/스타일로 승격 검토
- 색상·간격·폰트 토큰은 기존 전역 토큰/클래스를 우선 사용

## 금지

- 이모지로 상태 아이콘 대체
- 공용 컴포넌트 `className` 계약을 깨는 스타일 덮어쓰기
- 페이지 전용 임시 스타일을 무분별하게 전역 CSS로 이동
