# Grill Me 검토

## Method Guardrails (검토 방법 안전장치)

- [x] neutral question-first 적용 여부
- [x] 질문이 검토자를 특정 구현 선택으로 유도하지 않는지 여부

별도 grill-me 인터뷰 세션은 열지 않았다. 아래 행은 사용자가 제공한 refresh 스펙으로 닫힌 분기만 기록한다.

## Neutral Question Flow (중립 질문 흐름)

| 영역 | 중립적 질문 | 답변 | 근거 | Recommended Answer (권장 답변) |
| --- | --- | --- | --- | --- |
| 요청 | refresh 본문은 무엇인가? | `{ refreshToken }` | 사용자 스펙 예시 | 기존 DTO 유지 |
| 인증 | refresh에 Bearer를 붙이는가? | 인증 없이 호출 | 사용자 스펙 | 인증 Axios 인터셉터 없음 유지 |
| 수명 | 리프레시 토큰을 재사용할 수 있는가? | 1회용, 응답 토큰으로 교체 | 사용자 스펙 | 성공 시 persist로 교체, 전송 전 저장값 제거 |
| 실패 | 이미 쓴 토큰을 다시 보내면? | 계정 리프레시 토큰 전부 폐기, 재로그인 | 사용자 스펙 | 중복 전송 금지, 실패 시 세션 삭제 |

## 결론

닫힌 분기는 세션 회전에 반영했다. 열려 있는 것은 탭 간 잠금과 실패 후 로그인 화면 이동이다.
