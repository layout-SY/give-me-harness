# 평가 로그

## 현재 판정과의 경계

여기서는 Watcher 판정을 다시 평가하지 않는다.

## 장기 관찰 사항

- `sy-main` → `main` PR은 기능 단위가 아니라 2주치 114커밋 일괄이다. 리뷰 부담이 크다. 이후에는 시민참여 / 인증 / 셸을 나누는 편이 추적에 유리하다.
- `/login`이 `LoginTestPage` 이름인 채 라우트에 붙어 있다. 프로덕션 가드와 테스트 페이지 경계를 나중에 이름을 맞출 여지가 있다.
- 로그인 성공 시 토큰을 `oasisapp://login` 쿼리에 넣는 동작과, Deep Link 설계 문서의 “토큰을 URL에 넣지 않는다”는 목표가 어긋난다.

## 목록에 등록할 재사용 가능 자산

없음. 이 세션은 신규 컴포넌트를 만들지 않았다. `src/shared/ui/tabs`는 이미 `sy-main`에 있다.

## 기술 부채

- 미인증 사용자를 시민참여 mutation에서 로그인으로 보내는 라우트 가드가 이 diff에 없다.
- `.codex` 로그가 과거 커밋에 들어 있고 `.gitignore`는 이후부터 무시한다. `main` 머지 후 히스토리에 세션 파일이 남는다.

## 프로세스 개선 사항

큰 브랜치를 `main`에 올리기 전에 기능별 PR 정의를 먼저 쓰면 리뷰 질문이 줄어든다.
