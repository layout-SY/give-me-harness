# 평가 로그

## 현재 판정과의 경계

Watcher 판정을 다시 평가하지 않고, 이번 이전에서 재사용할 수 있는 장기 지식과 남은 기술 부채만 기록한다.

## 장기 관찰 사항

- RTC 자원은 기능 내부에서 소유하고 세션 세대와 게시 세대로 비동기 완료의 유효성을 판정해야 한다.
- 로컬 카메라·마이크 해제는 원격 구독 해제를 기다리지 않고 먼저 실행해야 한다.
- 사용자 UI의 공용 배지는 도메인 상태를 해석하지 않고 소비자가 레이블과 색조를 제공해야 한다.
- 저장소 훅은 셸 쓰기 동작을 추측하기보다 승인 전 읽기 전용 명령·도구만 명시적으로 허용하고 미분류 local/MCP 도구를 기본 거부하는 방식이 안전하다.

## 목록에 등록할 재사용 가능 자산

- `useApi`: 독립 요청, 명시적 취소 결과, 언마운트 중단
- `imageOriginPolicy`: 현재 출처·API 출처·명시적 공개 HTTPS 출처만 허용
- `rtcLifecycle`: 세션·게시 세대, 단일 실행, 키별 작업 직렬화
- `rtcSessionCleanup`: 즉시 로컬 자원 해제와 실패 집계
- 하네스 적대적 회귀 테스트: 승인·셸·미분류 MCP·무결성·상태·스테이징·미추적 파일 경계

## 기술 부채

- Agora SDK가 포함된 주 번들의 크기 분할이 필요하다.
- 실제 서버 인가, 토큰 갱신, 장치 권한, 다중 참여자 동작은 승인된 시험 환경이 필요하다.
- 전체 공용 카탈로그는 의도적으로 이식되어 사용되지 않는 파일에 대한 유지보수 경고가 남을 수 있다.

## 프로세스 개선 사항

- 마이그레이션 인벤토리는 설명식 수치가 아니라 `git ls-files` 명령으로 재현한다.
- 최종 문서 번역에서는 파서가 소비하는 정확한 영문 표식을 예외 목록으로 먼저 고정한다.
- 화면 변경 후에는 전체 페이지 캡처의 `sticky` 합성 특성을 구분하고 뷰포트별 순차 캡처를 사용한다.

## 권고 사항

- 배포 전 실제 Agora 시험 회의로 참여, 명시적 미디어 시작, 게시·구독, 토큰 만료·재입장을 확인한다.
- 후속 성능 작업은 현재 UX와 접근성을 유지하면서 Meeting 경로와 Agora SDK를 지연 불러오기한다.
