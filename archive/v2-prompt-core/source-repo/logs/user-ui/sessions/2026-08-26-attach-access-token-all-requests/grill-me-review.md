# Grill Me 검토

## Method Guardrails (검토 방법 안전장치)

- [x] neutral question-first 적용 여부
- [x] 질문이 검토자를 특정 구현 선택으로 유도하지 않는지 여부

별도 grill-me 인터뷰 세션은 열지 않았다. 아래 행은 구현 전에 사용자 대화에서 닫힌 분기만 기록한다.

## Neutral Question Flow (중립 질문 흐름)

| 영역 | 중립적 질문 | 답변 | 근거 | Recommended Answer (권장 답변) |
| --- | --- | --- | --- | --- |
| 적용 범위 | 어느 요청에 인증 헤더가 있어야 하는가? | 모든 API 요청 | 사용자: `모든 API 요청에 엑세스 토큰이 반영되어 있어야 한다` | `authRequired` 옵트인을 끄고 전송 계층에서 항상 붙인다 |
| 구현 위치 | 요청마다 `customConfig`를 추가하는가? | 전부 추가하되, 누락 없이 | 사용자: `인증 헤더 전부 추가해` | 요청 파일을 하나씩 고치면 다시 빠진다. 인터셉터가 전부를 덮는다 |

## 결론

닫힌 분기는 구현에 반영했다. 열려 있는 것은 토큰 부재 시 요청을 막을지다.
