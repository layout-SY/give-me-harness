# 스킬 인덱스

필요한 항목만 선택해서 불러옵니다.

- `policy/SKILL.md`: 전반에 적용되는 제약 조건
- `recipe/SKILL.md`: 반복 가능한 조립 흐름
- `reference/SKILL.md`: 재사용 가능한 UI와 훅 탐색

불러온 스킬은 `exploration.md`에 기록합니다. 역할은 누가 수행하는지를 설명하고, 스킬은 작업을 어떻게 수행하는지를 설명합니다.
