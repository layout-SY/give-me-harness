# 승인 게이트

애플리케이션 소스 또는 패키지를 변경하려면 계획 제시 후 사용자가 명시적인 메시지로 승인해야 한다. 정규화된 전체 프롬프트 또는 의미가 명확한 독립된 문장이 `진행`, `진행해줘`, `Proceed`, `작업 진행`, `승인`, `approved`, `go ahead` 중 하나여야 한다. 부정, 거부, 취소, 보류 문구를 먼저 처리하며, 이러한 문구는 절대 승인으로 간주하지 않고 이전 승인도 무효화한다. 직렬화된 이벤트 메타데이터는 승인 근거가 아니다. 탐색 및 거버넌스 전용 유지보수는 사용자가 명시적으로 요청한 경우 진행할 수 있다. 승인은 범위 확장 권한을 의미하지 않는다.
