# Audit Workflow

## 사용 조건

사용자가 Claude Code에 UI 평가를 명시적으로 요청한 경우에만 실행한다.

## 단계별 흐름

1. Evaluator가 요청된 UI 파일과 관련 계약을 직접 읽는다.
2. 별도 plugin, reviewer agent, 이미지 캡처 또는 시각 QA 없이 구조·접근성·소유권 위험을 분석한다.
3. 관찰 사실과 권고를 구분해 사용자에게 전달한다.
4. 사용자가 문서화를 요청하거나 결론 합의가 필요할 때만 `.claude/logs/**`에 기록한다.

## 제한

- 평가 과정에서 코드를 수정하지 않는다.
- 기능 로직의 품질 평가는 Hephaestus 범위로 돌려보낸다.
- 평가 결과를 자동 구현 작업으로 전환하지 않는다.
