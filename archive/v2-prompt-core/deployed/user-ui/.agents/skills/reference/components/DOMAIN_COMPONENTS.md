# 도메인 컴포넌트 카탈로그

아직 카탈로그에 등록된 대상 도메인 컴포넌트는 없습니다. 도메인 전용 컴포넌트는 해당 기능 가까이에 두고, 공용 UI로 이동하기 전에 승격 기준을 문서화합니다.
