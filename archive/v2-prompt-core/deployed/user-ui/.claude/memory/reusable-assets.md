# Reusable Assets

현재 재사용 자산의 단일 기준은 다음과 같다.

- 공용 UI 실제 소스: `src/shared/ui/`
- 디자인 계약: `DESIGN.md`
- 재사용 자산 목록: `.codex/memory/reusable-assets.md`
- 컴포넌트 탐색 규칙: `.agents/skills/reference/components/SKILL.md`
- 커스텀 훅 탐색 규칙: `.agents/skills/reference/custom-hooks/SKILL.md`

Claude Code는 목록을 이 파일에 복제하지 않는다. UI 작업마다 실제 소스와 현재 reference 문서를 다시 확인한다.
