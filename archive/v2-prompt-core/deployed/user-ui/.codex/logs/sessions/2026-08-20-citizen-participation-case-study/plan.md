# 계획

## 목표

완료된 시민참여 댓글·신고·제안 작업을 FSD 구조, 구현 이유, Mermaid 도식, 검증 근거, 이력서 문구, 멀티 에이전트 협업 평가를 포함한 재사용 가능한 기술 사례 문서로 작성한다.

## 범위

- 현재 코드의 계층·심볼·의존 방향 재탐색.
- 구현 구조와 두 사용자 흐름의 도식화.
- 관찰된 사실과 평가·권고 분리.
- 경력기술서, 짧은 bullet, STAR, 60초 설명 작성.
- Claude Code·Hephaestus 협업의 장점·비용·개선안 평가.

## 제외 사항

- 애플리케이션 코드와 package 변경.
- 범위 밖 전체 테스트 실패 수정.
- 관찰되지 않은 사업 성과나 성능 수치 추정.

## 승인

- 상태: approved
- 근거: 사용자 요청 `종합 문서 작성해봐`.
