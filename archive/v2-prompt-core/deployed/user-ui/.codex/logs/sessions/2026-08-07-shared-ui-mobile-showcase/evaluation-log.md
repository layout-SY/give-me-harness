# 평가 로그

## 현재 판정과의 경계

여기서는 Watcher 판정을 다시 평가하지 않는다.

## 장기 관찰 사항

- 공용 UI가 늘어나면 현재 feature 섹션에 시연을 추가해야 한다.
- 단일 production bundle의 기존 크기 경고는 별도 성능 작업에서 다룬다.

## 목록에 등록할 재사용 가능 자산

- `/ui-showcase`: 공용 UI 상태와 상호작용을 확인하는 내부 카탈로그.

## 기술 부채

- TypeScript LSP가 시스템에 설치되어 있지 않아 `tsc -b`로 진단을 대체했다.

## 프로세스 개선 사항

- 공용 컴포넌트 추가 시 카탈로그 시연과 `DESIGN.md` 계약을 함께 갱신한다.

## 권고 사항

- production bundle 크기 경고는 별도 승인 성능 작업에서 다룬다.
