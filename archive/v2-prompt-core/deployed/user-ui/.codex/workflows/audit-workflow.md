# 감사 워크플로

감사는 읽기 전용으로 수행해야 한다. 관련 정책을 불러오고, 근거를 조사하며, 발견 사항을 심각도에 따라 분류하고, 경로를 인용하며, 관찰된 결함과 권고 사항을 구분해야 한다. 변경을 제안하기 전까지는 승인이 필요하지 않다. 변경을 제안하는 즉시 변경 수행 워크플로로 전환하고 승인을 요청해야 한다.
