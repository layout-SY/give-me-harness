# 06 문서화와 핵심 규칙

작업 근거는 `.codex/logs/sessions/{YYYY-MM-DD-task-slug}/` 아래에 보관하고 템플릿을 사용한다. 애플리케이션 변경 시 필수 산출물은 계획, 탐색, 구현, Grill Me 검토, Watcher 검토, 평가, 최종 요약이다. 이전 로그는 현재 작업의 근거가 아니며 이번 마이그레이션 범위에도 포함하지 않는다.
