# 이력서·포트폴리오 기록 스키마

필수 항목: 하나 이상의 완전한 사례, 작업 유형, 관련 도메인/서비스, 문제 출처, 문제 상황, 고민과 선택, 적용, 사용 기술과 구체적 목적, 적용 전후 결과, 검증, 사용자 후속 피드백, 이력서 bullet, 포트폴리오 서술.

각 `## 사례 N — 제목`은 모든 필수 하위 항목을 포함한다. 사용자 대화·현재 실행·현재 코드에 없는 선택이나 성과를 추정하지 않으며, AI 하네스 변경도 동일한 사례 구조를 사용한다.
